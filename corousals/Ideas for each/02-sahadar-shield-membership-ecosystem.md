## Slide-by-Slide Copy

### 01 — Cover
- Eyebrow: `PROJECT: ECOSYSTEM`
- Dominant (headline): *"I built the membership system behind 300+ pharmacies."*
- Subordinate: *Sahadar Shield. Membership, credits, and discounts, unified across one ecosystem.*

### 02 — The Scale
- Eyebrow: `THE SCALE`
- Dominant (hero number): **`300+`**
- Subordinate: partner medical stores running one shared discount program, with no unified system behind it.

### 03 — The Problem
- Eyebrow: `THE PROBLEM`
- Dominant: *"Members, staff, and credits tracked without a system."*
- Subordinate: no consistent way to verify a customer, manage a membership, or move credits across hundreds of locations.

### 04 — The Solution
- Eyebrow: `THE APPROACH`
- Dominant: *"One ecosystem. Four applications."*
- Subordinate (stacked list): *Customer app / Customer portal / Staff dashboard / Admin dashboard*

### 05 — The Customer Journey
- Eyebrow: `THE JOURNEY`
- Dominant (4 numbered steps): *Register, Verify, Visit, Redeem*
- Subordinate: *"One phone number in. One membership card out. One ID that works in any store."*

### 06 — The Hard Part
- Eyebrow: `THE CHALLENGE`
- Dominant: *"One backend. Three different roles."*
- Subordinate: role-based permissions, branch-level access, and dual authentication (phone OTP plus Google) all had to hold together without conflict, across every login path.

### 07 — Outcome
- Eyebrow: `RESULT`
- Dominant: *"The largest system in the portfolio, running quietly in the background."*
- Subordinate: customers, staff, and admins now run on one platform, across every partner store.
- Accent: slate blue tag pill — `4 PLATFORMS. 1 ECOSYSTEM.`
