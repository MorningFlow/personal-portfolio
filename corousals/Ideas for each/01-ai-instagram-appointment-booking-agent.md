## Slide-by-Slide Copy

### 01 — Cover
- Eyebrow: `PROJECT: AUTOMATION`
- Dominant (headline): *"I built an Instagram inbox that books its own appointments."*
- Subordinate: *AI Appointment Booking Agent. Instagram DM automation.*

### 02 — The Problem
- Eyebrow: `THE PROBLEM`
- Dominant: *"Every DM answered by hand. Every reply a delay."*
- Subordinate: manual replies to booking inquiries were consuming hours daily and slowing response time for a service business fielding customers through Instagram.

### 03 — The Solution
- Eyebrow: `THE APPROACH`
- Dominant: *"An AI trained to sound like a person, not a bot."*
- Subordinate: personality modeled from real conversation history, so every reply matched the owner's actual tone.

### 04 — What I Built
- Eyebrow: `SYSTEM`
- Dominant (stacked list): *DM automation / Conversational AI / Personality modeling / Calendar booking / FAQ handling*
- Subordinate: *Instagram API, n8n, and an LLM, wired end to end.*

### 05 — The Hard Part
- Eyebrow: `THE CHALLENGE`
- Dominant (5 numbered steps): *Collect, Analyze, Profile, Engineer, Refine*
- Subordinate: *"Sounding human took five iterations, not one prompt."*

### 06 — Outcome
- Eyebrow: `RESULT`
- Dominant: *"No more manual replies. The inbox runs itself."*
- Subordinate: appointments book themselves, the voice stays personal.
- Accent: amber tag pill — `LIVE IN PRODUCTION`

### 07 — Try It (Live Demo)
- Eyebrow: `LIVE DEMO`
- Dominant: *"Message it yourself."*
- Subordinate: a live version of this agent runs on Instagram. Send "hi" to start the conversation.
- Link element (mono, tag-pill or ruled link style): `ig.me/m/mytaskengine`
- Small caption (mono, `--ink-40`, smallest weight in the deck): *Configured here as a sales assistant for demo purposes.*
