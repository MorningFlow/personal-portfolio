Project: Ecosystem01 / 07
I built the membership system behind 300+ pharmacies.
Sahakar Shield. Membership, credits, and discounts, unified across one ecosystem.
The Scale02 / 07
300+
Partner medical stores running one shared discount program, with no unified system behind it.
The Problem03 / 07
Members, staff, and credits tracked without a system.
No consistent way to verify a customer, manage a membership, or move credits across hundreds of locations.
The Approach04 / 07
One ecosystem. Four applications.
  • Customer app
  • Customer portal
  • Staff dashboard
  • Admin dashboard
The Journey05 / 07
1Register
2Verify
3Visit
4Redeem
"One phone number in. One membership card out. One ID that works in any store."
The Challenge06 / 07
One backend. Three different roles.
Role-based permissions, branch-level access, and dual authentication — phone OTP plus Google — all had to hold together without conflict, across every login path.
Result07 / 07
The largest system in the portfolio, running quietly in the background.
Customers, staff, and admins now run on one platform, across every partner store.
